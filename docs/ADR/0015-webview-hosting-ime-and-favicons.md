# ADR-0015: WebView のホスト方法・IME 余白・ブックマークアイコン

- 日付: 2026-11-01
- 状態: 採用（v1.4.0）
- 関連: ADR-0014（WebView 互換シム）, ADR-0004（ブックマーク永続化）

## 背景

v1.3.0 で DSH の Web UI は表示できるようになったが、実機では次の問題が残った。

1. チャット／軌跡パネルの背景が透明になり、上部 UI が欠けることがある。
2. キーボードを開くと入力欄がキーボードの下に隠れる。
3. ブックマークのアイコンが文字モノグラムだけで、サイトのアイコンにならない。

## 調査

エミュレータ（API 34 / WebView 113）で再現し、CDP で計測した。

- v1.3.0 は「Compose の `AndroidView` 直下に WebView を置くとレイアウトビューポート高さが 0 になる」
  問題を、CSS の `*vh` を実測 px に書き換えるシムで回避していた。この書き換えは
  ページの CSS を広範囲に改変するため、`100dvh` で組まれたパネルやオーバーレイの
  高さ・重なりを壊し、背景の消失や上部 UI の欠落を招くことがあった。
- 同じ WebView を **`FrameLayout` の中に MATCH_PARENT で入れる**と、ビューポートは
  最初から正しい値（例: 783px）になり、`vh` も正常に解決されることを確認した。
  つまり原因は「AndroidView の直接の子として WebView を置くこと」であり、
  CSS の書き換えは不要だった。
- キーボード: `enableEdgeToEdge()` + `adjustResize` では Compose 側が IME インセットを
  消費しないため、WebView は縮まず、固定配置の入力バーがキーボードに隠れていた。

## 決定

### 1. WebView は FrameLayout 経由でホストする

`AndroidView` の factory で `FrameLayout` を作り、その子として WebView を
`MATCH_PARENT` で追加する。これにより Chromium のレイアウトビューポートが
実サイズで初期化される。

### 2. `vh` 書き換えシムを削除する

根本原因が解消したため、v1.3.0 の `VIEWPORT_UNIT_FIX_JS` を削除した。
ページの CSS を書き換えないので、背景・重なり・固定要素が本来の設計どおりに描画される。

### 3. IME 余白を Compose で適用する

ブラウザ画面の Column に `Modifier.imePadding()` を追加し、キーボード表示時に
WebView 自体を縮める。`visualViewport` を見ている SPA（DSH など）も入力バーを
キーボード上へ移動できる。

### 4. ブックマークアイコンの自動取得

- 追加時に `glyph` が空なら `FaviconRepository` が取得を試みる（設定で OFF 可）。
- 取得順: `apple-touch-icon.png` → `apple-touch-icon-precomposed.png` → `favicon.ico`
  → ページ HTML の `<link rel="...icon...">`。180px のタッチアイコンを優先するのは、
  16px の `.ico` をタイルいっぱいに拡大すると潰れるため。
- ICO コンテナに PNG が埋まっている場合は PNG 部分を取り出してデコードする
  （Android の BitmapFactory は ICO を直接読めない）。
- 192×192 に正規化して PNG で `filesDir/bookmark_icons/<id>.png` に保存し、
  `Bookmark.icon` にはファイル名だけを持つ（JSON を肥大化させない）。
- 表示: アイコンがあるタイルは白背景＋`ContentScale.Fit`＋余白。文字モノグラムは
  従来どおりブランド色のタイル。
- ホーム画面ショートカットの Bitmap も同じアイコンを使う。
- 長押しメニューに「アイコンを再取得」（強制再取得）を追加。
- 削除時にアイコンファイルも削除。バックアップにはファイルを含めない
  （別端末ではモノグラムにフォールバックする）。

### 5. 取得時の安全性

- http(s) のみ。タイムアウト 5 秒、上限 256 KiB。
- HTTPS はページ監視と同じ証明書ピン（`SiteFetcher` の trust）に従う。
  未信頼の自己署名サイトからは取得しない。
- 認証情報は送らない（アイコンは公開リソースのため）。

## 影響

- vh シム削除により、ページの CSS は無改変で描画される。
- IME 表示中は WebView の高さが変わるため、ページはリサイズイベントを受ける。
- アイコンは端末ローカル。バックアップ復元直後は文字モノグラムになる。

## 検証

- API 34 / WebView 113: DSH のチャット・軌跡タブ、右パネル、上部バーが背景込みで表示。
  入力欄にフォーカスしてキーボードを出しても、入力バーがキーボード上に残る。
- Wikipedia のブックマーク追加でアイコンを取得し、白タイルに W が表示されることを確認。
- 111 JVM テスト、lint 0 errors。
